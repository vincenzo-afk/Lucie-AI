# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please report it by opening a private issue or contacting the maintainer directly at itsmebk2007@gmail.com. We will acknowledge your report and provide a timeline for a fix.
